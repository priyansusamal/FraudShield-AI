 FraudShield AI — Cyber Fraud Detection & Emergency Response System

FraudShield AI is a real-time AI-powered cyber fraud detection and intelligence platform that analyzes suspicious messages, detects scam patterns, visualizes fraud networks, and provides emergency SOS response features.

It is designed to help users identify scams like digital arrest fraud, OTP scams, phishing attacks, and banking fraud attempts.

Features
1. Scam Message Analyzer
Rule-based fraud detection engine
Detects:
Government impersonation scams
OTP / banking fraud
Urgency-based manipulation
Phishing links
Generates risk score (0–100)
Classifies scam type automatically
2. AI Investigation Report (Optional)
Uses Google Gemini API
Provides:
Risk explanation
Scam breakdown
Safety advice
Enhances human-readable analysis
3. Fraud Hotspots Map
Interactive map using Folium
Shows fraud-prone cities:
Delhi
Mumbai
Bangalore
Hyderabad
Visual intelligence layer for awareness
4. Fraud Network Graph
PyVis-based interactive graph
Visualizes scam ecosystem:
Scammer → Victims → Banks
Helps understand fraud flow patterns
5. Live Fraud Intelligence Feed
Simulated real-time fraud incidents
Color-coded alerts:
🟢 Safe
🟡 Medium Risk
🔴 High Risk
🆘 SOS Emergency System
One-tap emergency alert system
Generates:
Case ID
Incident timestamp
Risk status
Provides immediate safety instructions
